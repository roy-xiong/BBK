# 步步高经典游戏

Flutter Android 应用，离线内置《伏魔记》和《三国霸业》。Flutter 负责游戏选择、
设置、屏幕按键、震动、手柄输入和存档备份；原游戏逻辑运行在本地 WebView 中，不依赖
业务服务器或互联网资源。

## 功能

- 启动页选择《伏魔记》或《三国霸业》
- 三国霸业内置词典原版、原版精修和平衡版 2.1
- 原游戏存档同步备份到 Flutter 应用支持目录
- Android 手柄方向键、摇杆、A/B、LB/RB、X/Y 映射
- 可隐藏的屏幕按键与可关闭的点击震动
- 游戏默认竖屏，上方为 5:3 游戏画面，下方为红白机风格控制区
- 游戏内可一键切换横竖屏，横屏继续使用左右悬浮按键
- 两款游戏在前台游玩时保持屏幕常亮，退出游戏或切到后台释放常亮
- 伏魔记帮助面板显示当前故事目标、原存档对应的剧情进度和 8 个灯洞状态
- 默认完整流程同时安排主线与 20 个支线/分支节点，包含情书、寻女、老王去留、李府密道宝库及卡片任务，可切换为仅主线
- 原剧情二选一和多项选择通过弹窗由玩家决定；连续确认快读对白不会自动选中刚出现的分支
- 行人挡路时按实时碰撞重新规划，必要时正常让出空间并等待；仍保留真实道路、守卫、机关与道具条件
- 原版万能钥匙只有 3 把而锁箱有 5 处，显示余量、已暂缓及无法完成原因，不伪造额外钥匙
- 伏魔记横竖屏控制区均提供“一键前往当前目标”，地图面板保留同一入口
- 操作面板提供 96 个细分故事关卡，可搜索主线、支线与机关；选关自动补齐队伍、物品并佩戴芦藤甲/天心灯，不覆盖正常存档
- 自动跑路支持 1×、2×、3×、4× 循环切换；操作面板不再显示迷宫出口按钮
- 伏魔记默认使用 320×192 的 2× 逻辑画面：探索以 20×12 格填满画面，对话、菜单和战斗同步适配，可在控制区切回原视野
- 远视野对话与菜单使用原尺寸字形重新排版；系统四项同时展示，物品/法术列表每页八项，战斗背景延展、人物原尺寸绘制，避免把旧界面整体放大
- 迷宫出口导航包含地图门、NPC 楼梯及已持有引路石的原返回事件，保留原脚本通行条件
- 可沿已开放的真实出入口一键前往任务或地图位置，保留原剧情、机关和战斗
- 伏魔记完整等比例地图使用原游戏图块，包含 83 张室外、房屋和迷宫原图，支持缩放、格子和步行测距
- 浏览器独立地图入口为 `assets/games/fmj/atlas.html`；地图资源可用 `node tool/generate_fmj_guide.mjs --export` 重新生成并导出单文件 HTML

## 手柄映射

| 手柄 | 游戏动作 |
|---|---|
| D-Pad / 左摇杆 | 上下左右 |
| A / Start | 确认 |
| B / Select | 返回 |
| LB / RB | 上翻页 / 下翻页 |
| X / Y | 查找 / 帮助 |

## 说明

本地资源服务只监听 `127.0.0.1`。使用固定端口是为了保持 WebView localStorage 来源
稳定；端口冲突时会自动尝试备用端口，并通过 Flutter 存档镜像恢复数据。

第三方代码和资源说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
