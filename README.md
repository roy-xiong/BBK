# 步步高经典游戏

Flutter Android 应用，离线内置《伏魔记》《金庸群侠传》和《三国霸业》。Flutter 负责游戏选择、
设置、屏幕按键、震动、手柄输入和存档备份；原游戏逻辑运行在本地 WebView 中，不依赖
业务服务器或互联网资源。

## 功能

- 新首页为 84 款 RPG / Adventure 原机游戏库，支持搜索、收藏、最近游玩和机型选择
- 原有三款增强版从首页右上角星光按钮进入，存档及增强功能使用原有链路
- 原机游戏支持 ZIP 导入、原机键盘、1～8× 倍速、即时状态及通用内存作弊器
- 没有导入 GAM 或对应机型的两份 ROM 时，明确显示“资源待导入 / 缺少系统 ROM”

### 原机运行时构建与资源导入

Android 增加 Rust JNI 运行时。用户在 Android Studio 或 Flutter 中主动构建时，
Gradle 会调用 `tool/build_bbk_runtime.sh`，直接使用现有 NDK 的 Clang 链接器，无需 cargo-ndk。
工具链由 `third_party/bbkemu/rust-toolchain.toml` 固定到 Rust 1.99.0：

```bash
rustup toolchain install 1.99.0 --profile minimal --component rustfmt
rustup target add --toolchain 1.99.0 aarch64-linux-android armv7-linux-androideabi x86_64-linux-android i686-linux-android
```

当前代码编辑阶段没有执行编译。运行时不包含游戏 GAM 或系统 ROM：可在手机首页导入 ZIP，
ZIP 中保留原始 `游戏标题.gam`，系统 ROM 使用 `a4980/8.BIN`、`a4980/E.BIN`、
`a4988/8.BIN`、`a4988/E.BIN`。也可构建前使用本地目录导入：

```bash
node tool/import_bbk_assets.mjs --source /绝对路径/原机资源目录
node tool/import_bbk_assets.mjs --check
```

模拟器原机版和现有增强版的存档不互通。原机即时状态绑定 GAM、ROM 哈希和机型，
通用作弊器提供 8/16/32 位搜索、变化筛选、写入、锁定和批量作弊码导入。
84 款尚需真实 GAM/ROM 和设备回归；7 个上游 Warn 条目需要专项验证。
音频输出通道已接入，原机音频寄存器行为仍需验证，上游核心目前没有完整的硬件发声链路。

### 现有增强版能力

- 启动页选择《伏魔记》《金庸群侠传》或《三国霸业》
- 三国霸业内置词典原版、原版精修和平衡版 2.1
- 原游戏存档同步备份到 Flutter 应用支持目录
- Android 手柄方向键、摇杆、A/B、LB/RB、X/Y 映射
- 可隐藏的屏幕按键与可关闭的点击震动
- 游戏默认竖屏，上方为 5:3 游戏画面，下方为红白机风格控制区
- 游戏内可一键切换横竖屏，横屏继续使用左右悬浮按键
- 两款游戏在前台游玩时保持屏幕常亮，退出游戏或切到后台释放常亮
- 伏魔记帮助面板显示当前故事目标、原存档对应的剧情进度和 8 个灯洞状态
- 默认完整流程同时安排主线与 20 个支线/分支节点，包含情书、寻女、老王去留、李府密道宝库及卡片任务，可切换为仅主线
- 原剧情二选一和多项选择通过弹窗由玩家决定；连续确认快读对白不会自动选中刚出现的分支
- 行人挡路时按实时碰撞重新规划，必要时正常让出空间并等待；仍保留真实道路、守卫、机关与道具条件
- 原版万能钥匙只有 3 把而锁箱有 5 处，显示余量、已暂缓及无法完成原因，不伪造额外钥匙
- 伏魔记横竖屏控制区均提供“一键前往当前目标”，地图面板保留同一入口
- 操作面板提供 96 个细分故事关卡，可搜索主线、支线与机关；选关自动补齐队伍、物品并佩戴芦藤甲/天心灯，不覆盖正常存档
- 自动跑路支持 1×、2×、3×、4× 循环切换；操作面板不再显示迷宫出口按钮
- 伏魔记默认使用 320×192 的 2× 逻辑画面：探索以 20×12 格填满画面，对话、菜单和战斗同步适配，可在控制区切回原视野
- 远视野对话与菜单使用原尺寸字形重新排版；系统四项同时展示，物品/法术列表每页八项，战斗背景延展、人物原尺寸绘制，避免把旧界面整体放大
- 迷宫出口导航包含地图门、NPC 楼梯及已持有引路石的原返回事件，保留原脚本通行条件
- 可沿已开放的真实出入口一键前往任务或地图位置，保留原剧情、机关和战斗
- 伏魔记完整等比例地图使用原游戏图块，包含 83 张室外、房屋和迷宫原图，支持缩放、格子和步行测距
- 浏览器独立地图入口为 `assets/games/fmj/atlas.html`；地图资源可用 `node tool/generate_fmj_guide.mjs --export` 重新生成并导出单文件 HTML
- 金庸群侠传复用同一 RPG 引擎及 320×192 远视野，对话、菜单、战斗、高清和原视野切换一致
- 金庸群侠传原 ROM 含 32 张地图、170 个脚本、140 种物品，地图包含 37 个外景实例与 132 个室内实例，按 340 条真实入口关系展开
- 金庸群侠传支持真实逐格寻路、跨图前往当前主线/门派目标、地图点选前往、出口返回、1～4× 自动跑路和原自动战斗
- 金庸群侠传独立展示 9 个主线节点、11 个门派和 20 个标准支线/门派任务，完整流程安排已开放支线，拒绝的任务暂缓；选择、等级、物品和道路限制由原引擎决定
- 金庸群侠传提供 203 个故事/门派/场景选关节点，并可恢复选关前的独立备份，不覆盖三个正常档位
- 金庸群侠传作弊包含无敌、一击必杀、普通攻击群攻与先手、恢复、金钱、满属性、满级与主角可学武功、车票/材料、全物品、立即胜利及随机战斗开关
- 两款 RPG 共用高清设置；远视野、导航目标和存档独立，金庸存档在 WebView 中使用 `jyqxz:sav/*`，Flutter 镜像为 `saves/jyqxz.json`
- 金庸开关和倍率统一保存到 `bbk/jyqxz_controls`，随 Flutter 镜像恢复，既不继承 FMJ 开关，也不会重放金钱或升级等一次性作弊
- 金庸原版在四大城镇禁用存档，进入野外/门派再开放；快捷存档按钮保留此规则
- 金庸独立地图入口为 `assets/games/jyqxz/atlas.html`，`node tool/generate_jyqxz_assets.mjs --export` 可从固定 ROM 重建并导出 Downloads 下的单文件地图
- 金庸验证入口：`node tool/test_jyqxz.mjs`。浏览器验证不等同于 Android WebView 真机验证或全剧情通关

## 手柄映射

| 手柄 | 游戏动作 |
|---|---|
| D-Pad / 左摇杆 | 上下左右 |
| A / Start | 确认 |
| B / Select | 返回 |
| LB / RB | 上翻页 / 下翻页 |
| X / Y | 查找 / 帮助 |

## 说明

本地资源服务只监听 `127.0.0.1`。使用固定端口是为了保持 WebView localStorage 来源
稳定；端口冲突时会自动尝试备用端口，并通过 Flutter 存档镜像恢复数据。

第三方代码和资源说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
